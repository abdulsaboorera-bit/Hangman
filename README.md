# Hangman: Letter Quest

A polished single-player Hangman word-guessing game built with **React Native + Expo (SDK 58) + JavaScript**.

## Run the project

```powershell
cd HangmanGame
npx expo start
```

- **Phone:** Install Expo Go (Play Store) → scan the QR code
- **Emulator:** start an Android emulator, then press `a`

Run logic tests:

```powershell
node tests\gameLogic.test.mjs
```

## Game features

- 8 categories × Easy/Medium/Hard (~950 curated words)
- 6-stage friendly cartoon hangman (pure SVG, animated)
- Score: +10 letter, +50 word, +100 perfect, −20 hint
- Coins, high scores, stats — persisted with AsyncStorage
- Sound effects + haptics (individually toggleable in Settings)
- Pause, restart, 2 hints/round, one revive per loss
- Responsive keyboard for all Android screen sizes

## Monetization (AdMob)

Configured with **Google official test ad IDs** in `app.json`.

| Placement | Where | Behavior |
|---|---|---|
| Banner | Home | Adaptive banner, never during gameplay |
| Interstitial | After rounds | Every 3rd completed round |
| Rewarded | Revive / extra attempt | Opt-in only |
| Remove Ads | Future IAP | `setAdsRemoved(true)` in `src/services/ads.js` |

> **Important:** `react-native-google-mobile-ads` does **not** run inside Expo Go.
> In Expo Game the app gracefully falls back (banner hidden, free revive).
> Real ads require a development build or production build (below).

### Swap in production ad IDs

Replace the test IDs in `app.json` (plugin `androidAppId` / `iosAppId`) and
`src/services/ads.js` (`AD_UNIT_IDS`) with your AdMob IDs **after** creating an
AdMob account and registering the app. Keep test IDs until you submit.

## Build APK / AAB (Android)

### Option A — EAS Build (recommended, no Android Studio needed)

```powershell
npm install -g eas-cli
eas login
eas build:configure
```

Create `eas.json` (if not present) with `development`, `preview`, `production` profiles.

```powershell
# APK for testing
eas build -p android --profile preview

# AAB for Play Store
eas build -p android --profile production
```

### Option B — Local build

```powershell
npx expo run:android        # dev build with native modules (AdMob)
# or
eas build -p android --local
```

To get a Play Store **AAB** locally, use `gradlew bundleRelease` inside the
generated `android/` folder after `npx expo prebuild`.

## Google Play Store publishing checklist

1. Create a Google Play Developer account ($25 one-time).
2. Complete **Data safety form** (app collects only local stats — no personal data).
3. Publish a **privacy policy URL** (required for ads). Host a simple page and
   update `PRIVACY_POLICY_URL` in `src/screens/SettingsScreen.js`.
4. Prepare store assets: 512×512 icon, 1024×500 feature graphic, 4–8 screenshots,
   short & full description.
5. Upload the **AAB** to a closed testing track first → test → promote to production.
6. Set the app's **content rating** questionnaire (Everyone / PEGI 3 style).
7. Configure AdMob app → link Play Store listing → replace test ad IDs.
8. Review Play policies: ads must not mimic system UI; no intrusive interstitials
   during gameplay (already satisfied).
